# UX study template (owner fills this in)

Use the official Codex app normally, with your own account. For each workflow write short notes in your own words: **what you do, what you see, what felt good, what felt bad, what is missing.** No screenshots or assets go into this repo. Claude turns the notes into docs/UX-STUDY.md and feeds docs/FEATURE-MATRIX.md.

Workflows:

1. Start a project and a first chat
2. Run parallel threads / use a worktree
3. Set a goal (and a token budget)
4. Use plan mode
5. Steer a running turn vs queue a follow-up
6. Review a diff, and use review mode
7. Fork, revert, compact a thread
8. Change permission mode / approve an action
9. Schedule a task (standalone and inside a chat)
10. Open the browser pane and comment on a page element
11. Install and use a skill; install a plugin
12. Add an MCP server and sign in to it
13. Edit AGENTS.md / personalization / memories
14. Change theme, fonts, keyboard shortcuts, notifications
15. Check usage and rate limits
16. Archive and restore a thread

Note format per workflow:

```
## <n>. <name>
Did:
Saw:
Good:
Bad:
Missing:
```
