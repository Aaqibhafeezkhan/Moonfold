# Phase 8 plan: launch assets

Goal (BUILD-PLAN Phase 8, LAUNCH-PLAN section 2): the assets a stranger needs to go from the
README to a first task.

## Steps

1. README: a demo GIF of the handoff at the top, three value props, the install one-liners, the
   generated provider matrix, a dated and fair comparison, a "how handoff works" diagram, an FAQ,
   the disclaimer, license and credits.
2. Demos recorded from the real app (not mock data): handoff; browser pane plus scheduled tasks;
   plugins plus memories. A throwaway repository and a scratch Moonfold home, never the owner's
   projects; hostnames and local paths blurred.
3. A 1280x640 social preview image rendered from the brand mark.
4. A user documentation site on GitHub Pages built from `docs/user`.
5. CHANGELOG, ROADMAP; CONTRIBUTING already exists.
6. Repository description and topics, Discussions on, and 15 good-first-issues taken from the open
   items in QA-REPORT, PROGRESS and the docs.

## Not possible here

The BUILD-PLAN gate asks to test the README-to-first-task path on another person. That needs a
human outside this session and is left to the owner. The social preview image is uploaded in the
repository settings by hand (GitHub has no API for it).
