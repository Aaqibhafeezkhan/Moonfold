The second Moonfold beta: a new look, OpenCode handoffs from our first outside contributors, and
fixes from the first week. Moonfold is an open-source desktop and web workspace for coding agents,
built on [T3 Code](https://github.com/pingdotgg/t3code). It is not affiliated with or endorsed by
OpenAI, Anthropic, Google, Cursor or any other provider; it runs their CLIs with your own logins.

> [!WARNING]
> This is a beta. The installers are **not signed**: macOS and Windows will warn before the first
> launch. [Install and first run](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/install.md)
> explains how to open them. Back up anything important before letting an agent change it.

## What's new

- **A new mark.** The app icon, favicons, installer artwork and docs site use the new ringed-moon
  logo, and the command-line installers draw it in your terminal while they work.
- **OpenCode hands off at its usage limit.** OpenCode's limit errors now start a handoff like
  Codex and Claude Code do, instead of showing as an ordinary error. Thanks to
  @Aaqibhafeezkhan (#17).
- **Edit this page** links on every page of the
  [docs site](https://mr-dark-debug.github.io/Moonfold/). Thanks to @sadhana-s-codez (#16).
- After a handoff, the composer stays on the thread's new agent instead of switching back.
- Releases are listed as the latest release on GitHub, and every update check, installer and
  model or schema download points only at this repository.

## Install

- **Desktop:** download the `.dmg` (macOS), `.exe` (Windows), or `.AppImage` / `.deb` (Linux) for
  your machine below. Beta 1 installs update to this release on their own.
- **Command line:** `curl -fsSL https://raw.githubusercontent.com/Mr-Dark-debug/Moonfold/main/scripts/install.sh | sh`
  (macOS and Linux), or in PowerShell
  `irm https://raw.githubusercontent.com/Mr-Dark-debug/Moonfold/main/scripts/install.ps1 | iex`.
- `SHA256SUMS` lists a checksum for every file, and the SBOM (`*-sbom.cdx.json`) lists every
  dependency.

## Known limits

- Installers are unsigned (see above).
- Starting the desktop app takes about 4 seconds on a mid-range Windows laptop before the window
  is usable; a splash shows within a second.
- Verified on real installs: Codex CLI and Claude Code on Windows 11. Gemini CLI connects over
  ACP; use an API key or Vertex AI to sign in. Cursor, Grok Build and Antigravity are carried
  over from T3 Code and were not checked on a real install for this beta.
- Cursor and other ACP agents report usage limits as ordinary errors, so hand off from them by
  hand ("Hand off to…" in the thread menu).
- Computer use is Windows only.

Report problems at https://github.com/Mr-Dark-debug/Moonfold/issues. New contributors: issues
