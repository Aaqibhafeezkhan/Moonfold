The third Moonfold beta adds DeepSeek Harness, local models through Pi, prompt profiles and
scheduled messages. Moonfold is an open-source desktop and web workspace for coding agents, built
on [T3 Code](https://github.com/pingdotgg/t3code). It is not affiliated with or endorsed by
OpenAI, Anthropic, Google, DeepSeek, Cursor or any other provider; it runs their CLIs with your
own logins.

> [!WARNING]
> This is a beta. The installers are **not signed**: macOS and Windows will warn before the first
> launch. [Install and first run](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/install.md)
> explains how to open them. Back up anything important before letting an agent change it.

## What's new

- **DeepSeek Harness.** Add it from the agent search in Settings → Providers. Moonfold installs the
  pinned `@deepseek-ai/dsh` package and runs its ACP profile, with the models from your own
  DeepSeek Harness setup. DeepSeek's "Insufficient Balance" and quota errors start a handoff.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/providers-deepseek-harness.md).
- **Local models.** Turn on **Local models** for Pi and the models Ollama or LM Studio serve on your
  machine appear in the model picker, running through Pi's tools and approvals. Moonfold only looks
  for the servers; it never downloads or starts anything, and it does not edit your `~/.pi`. A
  local model has no usage limit, which makes it a good last fallback for handoff.
- **Prompt profiles.** Standing instructions Moonfold sends with every turn, to every agent: pick a
  default in Settings → Prompt Profiles, or one for a single thread from its menu. Five built-ins
  (Moonfold default, Careful engineer, Terminal-first, Pair programmer, Minimal) and your own.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/prompt-profiles.md).
- **Schedule a message.** Right-click **Send**, or type `/timed tomorrow 9am run the tests`, to send
  a message into the thread later, with the agent and model you choose. It survives restarts and
  waits behind running work. When an agent hits its limit, the notice offers to schedule a message
  for the reset.

## Install

- **Desktop:** download the `.dmg` (macOS), `.exe` (Windows), or `.AppImage` / `.deb` (Linux) below.
  Earlier betas update to this release on their own.
- **Command line:** `curl -fsSL https://raw.githubusercontent.com/Mr-Dark-debug/Moonfold/main/scripts/install.sh | sh`
  (macOS and Linux), or in PowerShell
  `irm https://raw.githubusercontent.com/Mr-Dark-debug/Moonfold/main/scripts/install.ps1 | iex`.
- `SHA256SUMS` lists a checksum for every file, and the SBOM (`*-sbom.cdx.json`) lists every
  dependency.

## Known limits

- Installers are unsigned (see above).
- DeepSeek Harness was checked with a local model only; its DeepSeek-API limit signals are covered
  by tests, not a live account. Through ACP it shows no plans, todos or terminal views of its own.
- Small local models (around 1–2B parameters) handle tool calls poorly; use a coding model of 7B or
  more.
- Prompt profiles were checked live on Claude Code; on other agents they ride the same instruction
  channel Moonfold already uses, covered by tests.
- Scheduled messages carry text only.
- Desktop start to a usable window is still about 4 seconds on a mid-range Windows laptop.
