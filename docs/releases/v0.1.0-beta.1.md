The first Moonfold beta. Moonfold is an open-source desktop and web workspace for coding agents,
built on [T3 Code](https://github.com/pingdotgg/t3code). It is not affiliated with or endorsed by
OpenAI, Anthropic, Google, Cursor or any other provider; it runs their CLIs with your own logins.

> [!WARNING]
> This is a beta. The installers are **not signed**: macOS and Windows will warn before the first
> launch. [Install and first run](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/install.md)
> explains how to open them. Back up anything important before letting an agent change it.

## Highlights

- **Provider handoff.** When an agent stops at its usage limit, Moonfold offers to continue the
  same thread in another agent. You see the brief it will send (objective, plan, what you said,
  changed files, `git status` and `git diff --stat`, failing command) before it goes, and keys,
  tokens and passwords are redacted from it. Settings → Handoff sets a fallback order, which
  agents are allowed, and whether to ask first or move on automatically.
- **Works with Codex CLI and Claude Code**, plus agents that speak ACP (including Gemini CLI)
  and the other adapters inherited from T3 Code. The README's provider table lists what was
  checked on a real install.
- **Everything from T3 Code:** projects and threads, git worktrees, diff review and the pull
  request flow, permission modes, remote access from another device.
- **New in Moonfold:** scheduled tasks, plugins (Codex, Claude Code or plain SKILL.md), memories
  you can read and edit, a browser pane with per-site rules, Word and Excel previews, a thread's
  artifacts in its details panel, and computer use on Windows (off by default, approved per app).

## Install

- **Desktop:** download the `.dmg` (macOS), `.exe` (Windows), or `.AppImage` / `.deb` (Linux) for
  your machine below. Beta installs update themselves to the next beta from this repository's
  releases.
- **Command line:** `curl -fsSL https://raw.githubusercontent.com/Mr-Dark-debug/Moonfold/main/scripts/install.sh | sh`
  (macOS and Linux), or in PowerShell
  `irm https://raw.githubusercontent.com/Mr-Dark-debug/Moonfold/main/scripts/install.ps1 | iex`.
- `SHA256SUMS` lists a checksum for every file, and the SBOM (`*-sbom.cdx.json`) lists every
  dependency.

## Known limits

- Installers are unsigned (see above).
- Starting the desktop app takes about 4 seconds on a mid-range Windows laptop before the window
  is usable; a splash shows within a second. Making it faster is the next performance item.
- Verified on real installs: Codex CLI and Claude Code on Windows 11. Gemini CLI connects over
  ACP, but Google refuses its Google-account sign-in for individual accounts; use an API key or
  Vertex AI. Cursor, OpenCode, Grok Build and Antigravity are carried over from T3 Code and were
  not checked on a real install for this beta.
- Cursor, OpenCode and other ACP agents report usage limits as ordinary errors, so hand off from
  them by hand ("Hand off to…" in the thread menu).
- Computer use is Windows only.
- `npx moonfold` is not available yet; use the install script or the desktop app.

Report problems at https://github.com/Mr-Dark-debug/Moonfold/issues.
