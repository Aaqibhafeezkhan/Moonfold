Questions People
Often Ask

What exactly is Moonfold?+

Moonfold is an open-source, local-first workspace for coding agents, built on T3 Code. It brings projects, agent conversations, worktrees, and code review together. Its headline goal is continuity across providers when an agent reaches a usage limit.

Can I use it today?+

The source is available for developers to explore and build. Moonfold is still in early development; a packaged beta and the provider handoff experience are planned. For current setup instructions and progress, read the development guide.

Which coding agents does it work with?+

The T3 Code foundation includes adapters for Codex, Claude Code, Cursor, OpenCode, Grok, and Antigravity. Gemini CLI is planned for Moonfold. Availability and verification vary by provider; the progress log records what has actually been tested.

Do I need my own subscriptions?+

Yes. You use your own provider accounts and authenticated local tools. Moonfold is a workspace around those tools; it doesn’t include model credits or pool, share, or resell provider access. Each provider’s pricing and terms still apply.

How will provider handoff work?+

The planned workflow preserves a task brief with the goal, decisions, code changes, and open questions, so another provider can continue. Review before switching is the intended default. This is a roadmap feature, and native provider sessions aren’t interchangeable.

Is this an official provider app?+

No. Moonfold is an independent project and a fork of T3 Code. It is not affiliated with or endorsed by OpenAI, Anthropic, Google, Cursor, or T3. Provider names are used only to identify integrations.
